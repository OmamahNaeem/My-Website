## About This Project

Page Flippers is an online book store built as an AICT Academic Project (May 2026). The website allows users to browse and purchase books across three categories: **Urdu Novels**, **Islamic Holy Books**, and **Competitive Exam Books**.

The website was built using **Wix (Free Plan)** and features 23 book listings with prices in Pakistani Rupees (PKR).
